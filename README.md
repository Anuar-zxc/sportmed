# AI Sports Precision Medicine — сайт

Лендинг национальной ИИ-платформы медицинской персонализации спортсменов (Digital Athlete Twin) с юридическими страницами.

**Демо-дашборд команды:** https://ai-sport-pearl.vercel.app

## Страницы

| Путь | Содержание |
|---|---|
| `/` | Главная: проблема, цифровой двойник, данные, 6 модулей ИИ, пилот, рынок, безопасность, FAQ, заявка |
| `/privacy` | Политика конфиденциальности |
| `/cookies` | Политика cookie |
| `/terms` | Пользовательское соглашение |
| `/consent` | Согласие на сбор и обработку персональных данных |
| `/404` | Страница «не найдено» |

## Технологии

- Статический HTML, CSS и JavaScript без фреймворков и сборки — быстро и без зависимостей.
- Шрифты Montserrat, Manrope и JetBrains Mono (SIL Open Font License) отдаются через собственный домен (rewrite `/gf/*` в `vercel.json`): браузер посетителя не обращается к сторонним CDN.
- Баннер cookie с категориями «Необходимые» и «Аналитика». Аналитика (Vercel Web Analytics, без cookie) загружается только после согласия.
- Заголовки безопасности (CSP, HSTS и др.) и «чистые» адреса без `.html` настроены в `vercel.json`.
- Доступность: семантическая разметка, навигация с клавиатуры, `prefers-reduced-motion`, контраст по WCAG AA.

## Деплой

Репозиторий подключён к Vercel: каждый push в `main` публикуется автоматически. Настройки проекта:
Framework Preset — **Other**, Build Command — пусто, Output Directory — `.` (корень).

Локальный просмотр:

```bash
npx serve .
```

## Что обновлять

- **Контакты и оператор персональных данных** указаны в юридических страницах, `index.html` и `main.js` (`CONFIG.email`). Когда появится юридическое лицо (ТОО/ИП), добавьте наименование, БИН и адрес в разделы «Оператор» и «Контакты».
- **Домен**: при подключении собственного домена замените адрес в `canonical`, `og:url`, `robots.txt` и `sitemap.xml`.
- **Документы** версионируются: при изменении поменяйте номер редакции и дату вступления в силу.

> Юридические тексты подготовлены на основе законодательства Республики Казахстан о персональных данных и здравоохранении. Перед запуском пилота их рекомендуется согласовать с юристом.
