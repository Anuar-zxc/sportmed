# Модели AI Sports

Две модели, обученные на открытых научных данных. Инференс выполняется **в браузере** (`/model.js` + `/models.js`), данные пользователя никуда не отправляются.

| Модель | Задача | Данные | Алгоритм | Качество (кросс-валидация по людям) |
|---|---|---|---|---|
| `injury_risk` | Вероятность травмы на следующий день → оценка на 7 дней | Lövdal et al., 2021 — 74 бегуна, 42 766 дней, 583 травмы (CC0 1.0) | HistGradientBoosting + калибровка Платта | ROC-AUC **0,617** (95% ДИ 0,58–0,65) vs 0,528 у модели «только нагрузка»; верхний дециль — ×1,8 травм |
| `readiness_next_day` | Самооценка готовности завтра (0–10) | SoccerMon, команда B — 22 игрока, 4 770 пар дней (CC BY 4.0) | Huber-регрессия | MAE **0,625**, R² 0,53 vs «как сегодня» MAE 0,658, R² 0,28 |
| — «плохой день» | Готовность завтра ≤ личная норма − 1 СКО | то же | HistGradientBoosting + Платт | ROC-AUC **0,695** (95% ДИ 0,64–0,74) vs правило 0,634 |

Полные метрики, кривые калибровки и важность признаков — в `models/*_card.json` и на странице **Модели ИИ** демо-кабинета.

## Принципы

- **Без утечки будущего.** Признаки на день *t* используют только дни до *t* (риск травмы) или до *t* включительно для прогноза на *t+1* (готовность). В выгрузке бегунов перед травмами нет истории длиннее 7 дней, поэтому признаки с окнами 14–28 дней «узнавали» травму по пропускам (AUC 0,95) — они исключены.
- **Переносимость.** Модель риска применяется к другим видам спорта, поэтому все признаки относительные: к личной норме спортсмена (нагрузка, интенсивность, число тренировок, z-оценки самочувствия) или безразмерные (монотонность, дни отдыха).
- **Честная валидация.** `GroupKFold` по спортсменам, сравнение с базовыми линиями, бутстрэп-интервалы по спортсменам, калибровка.
- **Объяснимость.** Для каждого прогноза риска — вклад признаков по пути в деревьях (Saabas); для готовности — вклад групп признаков линейной модели.
- **Совпадение Python и JS.** `verify_js.py` генерирует случайные ряды с пропусками и сверяет признаки и прогнозы браузерной реализации с Python (расхождение < 1e-6, фактически ~1e-15).

## Воспроизведение

```bash
pip install -r ml/requirements.txt
ml/fetch_data.sh
python ml/train_injury.py ml/data/runners/day_approach_maskedID_timeseries.csv ml/out
python ml/train_readiness.py ml/data/soccermon/data/modeling/paper_inspired ml/out
python ml/build_web.py ml/out .      # обновляет models.js и ml/models/
python ml/verify_js.py               # нужен Node.js
```

Файлы: `features.py` — признаки (зеркало в `/model.js`), `export.py` — экспорт деревьев в JSON, `train_*.py` — обучение и карточки моделей, `build_web.py` — сборка `models.js`.

## Ограничения

- Модель риска обучена на бегунах, модель готовности — на футболистках одной команды. Перед клиническим применением — дообучение и проверка на данных своей команды, сначала в shadow-режиме.
- Точность умеренная (типично для прогноза травм по нагрузке и самочувствию). Прогноз — повод для внимания специалиста, не диагноз и не допуск к тренировкам.
- Это не медицинское изделие.
