# AI Sports — приложение для iPhone

Нативное приложение на SwiftUI (iOS 17+), без сторонних библиотек. Две роли в одном приложении:

| Роль | Что делает |
|---|---|
| **Спортсмен** | Утренний чек-ин (те же вопросы, что на сайте), шифрование ответа на телефоне и отправка ссылкой через мессенджер; персональная ссылка — из QR-кода или буфера; браслет по Bluetooth LE (пульс, HRV по RR-интервалам, заряд); Apple Health (HRV, пульс покоя, SpO₂, сон, температура с Apple Watch); история отправленных чек-инов. |
| **Специалист** | Полный кабинет врача / тренера / психолога внутри приложения (работает офлайн, данные команды на устройстве), приём ссылок-ответов из буфера или через «Поделиться». |

Шифрование совместимо с веб-версией байт в байт: HKDF-SHA256 → AES-256-GCM, проверяется юнит-тестами на векторах, сгенерированных `asp-crypto.js`.

## Структура

```
ios/
  project.yml              спецификация XcodeGen (цели, Info.plist, права)
  AISports/
    App/                   точка входа, состояние, тема, выбор роли
    Shared/                ASPCrypto (крипто и ссылки), модели, хранилище (Keychain + файлы)
    Athlete/               Сегодня, Чек-ин, Ссылка/QR, История
    Athlete/Band/          BandManager (CoreBluetooth), экран браслета
    Athlete/Health/        HealthProvider (HealthKit)
    Specialist/            кабинет в WKWebView, входящие
    Resources/             иконка, цвета
  AISportsTests/           XCTest: крипто-векторы, разбор ссылок, разбор пакета пульса BLE
```

## Запуск на Mac

```bash
brew install xcodegen
cd ios && xcodegen generate
open AISports.xcodeproj
```

В Xcode: **Signing & Capabilities → Team** — выберите свой Apple ID (бесплатный Personal Team достаточно, чтобы запускать на своём iPhone; срок подписи 7 дней, затем пересобрать). Подключите iPhone кабелем, выберите его как устройство и нажмите ▶. На телефоне: Настройки → Основные → VPN и управление устройством → доверять разработчику.

Публикация в TestFlight / App Store потребует аккаунт Apple Developer Program ($99/год) и заполненный `DEVELOPMENT_TEAM` в `project.yml`.

Тесты: `⌘U` в Xcode или

```bash
xcodebuild test -project AISports.xcodeproj -scheme AISports -destination 'platform=iOS Simulator,name=iPhone 15'
```

CI ([`.github/workflows/ios.yml`](../.github/workflows/ios.yml)) собирает проект и гоняет тесты в симуляторе на каждом изменении в `ios/`.

## Как это связано с сайтом

- Персональная ссылка (`…/checkin#v1.<team>.<athlete>.<key>.<имя>`) та же, что выдаёт кабинет — её можно отсканировать с экрана кабинета или вставить из чата.
- Ответ (`…/app#ci=<team>.<athlete>.<blob>`) открывается и в веб-кабинете, и в приложении специалиста.
- URL-схема `aisports://` и ссылки сайта, переданные в приложение через «Поделиться», обрабатываются одинаково: приглашение сохраняется у спортсмена, ответ попадает во «Входящие» специалиста.

## Браслет

Сейчас — стандартные профили Bluetooth SIG: Heart Rate (0x180D, пульс и RR-интервалы → RMSSD) и Battery (0x180F). Фирменный SDK производителя (Goodwaytechs V500 / E600: SpO₂, температура, сон, память за ночь) подключается через протокол `BandProvider` в `BandManager.swift`, когда будет получен. Для фоновой связи включён режим `bluetooth-central`.

## Безопасность

- Ключ приглашения — в Keychain (`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`), история — в Application Support с защитой файлов.
- Ничего не отправляется на сервер приложения: его нет. Ответы уходят только тем каналом, которым спортсмен сам поделился ссылкой.
- Кабинет в приложении ограничен доменом сайта (`WKAppBoundDomains`), внешние ссылки открываются в системе.
